## English -> Turkish translation

chrF (0-100) against one reference translation per phrase.

| Phrase set | No glossary | M1 glossary | Improved glossary |
|---|---|---|---|
| Main (30 phrases, used to tune the glossary) | 33.8 | 42.9 | 55.2 |
| **Held-out** (20 phrases, never used for tuning) | 42.0 | 45.5 | **48.8** |

The held-out set (`data/eval/en_tr_phrases_holdout.toml`) was committed before
the glossary was tuned, and terms that appear only there ("gj", "smurf",
"one tap", "push") were deliberately left out of the glossary. Its score is the
honest estimate; the main-set score is optimistic because the glossary was
adjusted while looking at it.

## Translation engines

chrF with the glossary on; time is the average per phrase on the CPU with 4 threads.
The Russian set (`data/eval/ru_tr_phrases.toml`) was written for this comparison.

| Phrase set | Argos | NLLB-600M | NLLB-1.3B |
|---|---|---|---|
| English held-out | 48.8 | 55.8 | **63.5** |
| English main | 55.2 | 60.6 | 60.1 |
| Russian | 29.2 | 36.5 | **42.1** |
| Time per phrase | 46-90 ms | ~300 ms | ~550-735 ms |

NLLB is not faster on the GPU (measured on an RTX 4060), so translation stays on the CPU.
Both engines fail on Russian gamer slang ("флешка", "калаш", "ретейкать"); a Russian glossary
with its own held-out set is the next step. Reports: `engines-*.md`.
